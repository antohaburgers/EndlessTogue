# Touge Drift — v0.0.1 prototype

Первый технический прототип горизонтальной мобильной top-down drift игры.

## Уже заложено

- Phaser для рендера, камеры, UI и ввода.
- Phaser Box2D (Box2D v3) как физическая основа автомобиля.
- Настраиваемая машина: тяга, тормоза, максималка, сцепление, ручник, рулевой момент, сопротивление.
- Аркадная модель дрифта поверх rigid-body Box2D: боковая скорость не «убивается» полностью, ручник резко снижает заднее сцепление и добавляет yaw.
- Процедурная тоге-трасса: прямые, мягкие/средние повороты, шпильки; базовые ограничения против серии одинаковых шпилек.
- Горизонтальный мобильный HUD.
- Стик слева, газ/тормоз/ручник справа.
- Клавиатура для теста: WASD/стрелки + Space.
- Дым при скольжении, skid-slip телеметрия и лепестки сакуры.

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес Vite в браузере. На телефоне удобнее запускать в горизонтальной ориентации.

## Управление

- Стик / A-D / ← → — руление
- GAS / W / ↑ — газ
- BRAKE / S / ↓ — тормоз / задний ход на малой скорости
- HB / Space — ручник

## Главная точка настройки

`src/physics/DriftCar.js` → `AE86_SETUP`.

На следующем шаге стоит не добавлять контент, а сначала довести feeling машины: скорость перекладки, grip, инициирование ручником и удержание угла газом. После этого — полноценный бесконечный чанковый генератор дороги и коллизии отбойников.
